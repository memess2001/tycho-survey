**Claude:** 我基本同意，但想补三点。

关于第谷和伽利略

缺一份系统、可比较的星表，这个判断是对的。grokking、双下降、cone effect，都是各自在一个特定设置上被发现的，换个配置还在不在、边界在哪里，基本没人系统地测过。这很像第谷之前的天文学：观测零散，误差不明，彼此对不上。

但我有三点补充：

第谷的价值在精度和系统性，不在数量。 开普勒放弃圆轨道，是因为火星位置和圆轨道差了 8 角分。他之所以敢为这 8 角分推翻整个模型，是因为他相信第谷的仪器误差比这小。对我们来说，星表里一个反常只有在知道仪器误差时才有意义。所以项目一的校准就是在造第谷的仪器，必须先于巡天。
我们在时间线上其实是混着的。 开普勒式的经验律已经有了：scaling laws 是很漂亮的幂律，但没人知道为什么成立。望远镜也有好几架：SAE、探针、归因图。真正缺的是对训练动力学的系统巡天。
我们比第谷幸运。 天空不会因为你重看一遍而改变，但训练可以换个种子重放，也可以改一个参数再跑。所以这门学问更像巡天加实验生物学：先巡出现象，再用干预去验证机制。另外，开普勒最初的假说是柏拉图多面体，错得很漂亮。星表最大的价值之一，就是证伪那些好听的故事。

可解释性、SAE 和你的计划是什么关系

SAE 和机制可解释性回答的是"里面有什么"：哪个方向对应哪个词、哪个概念，而且大多只看一个 checkpoint，像光谱分析。你的计划回答的是"哪些变量在训练的哪一步开始以几阶的方式一起起作用"，像光变曲线，而且刻意不管变量是什么意思。所以计划里没有 token：这是一套不依赖语义的坐标。好处是它能用在 RL、玩具模型、Lenia 上；代价是一个"子集 {A,B,C} 在第 t 步激活"的事件，如果 A、B、C 没有含义，就读不出东西。

三座可以搭的桥：

用 SAE 特征做 RI 的变量。 SAE 特征稀疏、接近单义，天然可以二值化成"亮或不亮"，正好绕过 RQ0 里最难的离散化。这样 RI 测的就是"哪些概念组合在第几步开始被一起使用"。跨 checkpoint 保持特征身份，可以借 SAE-Track 的做法：每个 checkpoint 的 SAE 都从上一个初始化。
一个可检验的分歧。 SAE-Track 在 Pythia 和 GPT-2 上发现，单个特征的形成大多是平滑的：词元级特征很早就有，概念级特征慢慢长出来。你的假设是交互会突然激活。两者可以同时成立：特征平滑地长出来，特征之间的高阶交互却突然接通。这正是 RI 能看到、SAE 看不到的东西，值得写进 RQ3。
直接用 token 做变量。 在上下文马尔可夫链任务上，transformer 会分阶段学会越来越高阶的统计，阶段之间有跳变（Edelman 等 2024）。语言的阶数由你设定，所以答案已知：RI 应该在对应的阶上报出激活，时间也应该对得上那几次跳变。这就是带 token 的阳性对照。
这样你是把可解释性当仪器在用，课题本身仍然是训练动力学，也符合你想往预训练科学定位的方向。

项目三怎么落地

先校准，再巡天。 项目一就是项目三的第一期。
两级观测，照搬 SDSS 的做法。 所有配置先跑便宜的"测光"：loss、权重范数、有效秩、eNTK 统计这类每步都能算的量。只有被标成异常、或者落在边界上的配置，才做昂贵的 RI"光谱跟进"。RI 太贵，不能给每个天体都拍光谱。
星表格式。 每次训练是一个天体，记录配置、种子、各坐标的光变曲线，以及 RI 事件：哪个子集、几阶、第几步激活、置信度多少。另外开一个暂现源通道：晚激活、激活后又熄灭、回滞，这类事件第一时间推给你。天空里除了之前那些旋钮，再加上马尔可夫链语言这类带 token 的任务。
巡天策略。 先用粗网格均匀覆盖，再由 agent 把算力集中到发育时间线发生质变的边界。每个点用多个种子重复曝光，把信号和噪声分开。
agent 的分工。 每晚做质检，把新天体归到已知现象（grokking、双下降、平台期等），归不进去的放进"未知"队列等你看；提出下一批配置；写巡天日志。每周汇总成周报。
公开发布。 像 SDSS 那样定期发布星表和回放。别人能用你的星表去做他们的开普勒，这份工作的影响会远超一篇论文。
开普勒时刻可能长什么样。 比如"k 阶交互的激活时间和数据量呈幂律"，或者"激活顺序总是从低阶到高阶，只有某个区域例外"。这类跨配置的经验律，只有星表能给出来。
这个计划已经大到值得写成一份设计文档了：天空怎么定义、两级观测、星表格式、校准标准、agent 的规则。要的话我来起草，下周二可以带去给 Sugiyama 看。

**Claude:** "混着"的意思是：LLM 科学不是走在一条时间线上，而是有好几个研究对象，每个对象走到了不同的阶段。先把天文学的几个角色拆开，就好理解了。

四个角色，各自回答一个问题

仪器：能不能看见，看得多准。这里有两种。第谷是把已有的观测做到极准；伽利略是造出一种新的看法，看见以前根本看不见的东西，比如木星的卫星。
巡天：对很多对象，用同一把尺子，系统地记下来，形成星表。第谷几十年的观测就是最早的一份。
经验律：从星表里找出稳定的规律，只描述"是什么"，不解释"为什么"。开普勒三定律是这一类，后来的赫罗图也是：把几万颗星按颜色和亮度画上去，它们挤在几条带子上。
理论：解释为什么是这个规律。牛顿用引力推出了椭圆轨道，恒星物理用核聚变解释了赫罗图上的那几条带子。
链条是：仪器 → 巡天 → 经验律 → 理论，理论再催生新仪器。行星这条线在历史上是按顺序走完的。

LLM 科学的情况是，三个对象各在不同的位置：

| 研究对象 | 走到哪一步 | 天文学对应 |
|---|---|---|
| 训练完的模型，能力随规模怎么变 | 有经验律（scaling laws），没有公认的机制 | 开普勒之后，牛顿之前 |
| 一个模型内部有什么 | 刚有新望远镜，看到了新天体（特征、电路），规律很少 | 伽利略刚举起望远镜 |
| 训练过程怎么展开 | 只有零散的观测（grokking、双下降、归纳头），没有统一的尺子和星表 | 第谷之前 |

你的课题在第三行：先造一把校准过的尺子（RI），再做星表，给训练动力学找它的开普勒。

scaling laws 为什么成立

现象本身是：损失随模型大小、数据量、算力按幂律下降，在对数坐标上是一条直线。问题是为什么偏偏是幂律，指数又由什么决定。目前没有共识，主要有几类解释：

数据本身是幂律结构的。 自然数据的"信息量"分布很不均匀：数据协方差的特征值按幂律衰减，或者数据落在一个低维流形上。大小为 N 的模型只能分辨前 N 个方向，剩下的误差就是幂律的尾巴。Bahri 等人的 Explaining Neural Scaling Laws 和一批可解的随机特征模型都属于这条线。2026 年还有工作发现，用随机图这种极简的数据也能复现 scaling law，说明它可能是"从有结构的数据里学习"的普遍性质。
能力是一块一块学会的。 Michaud 等人的量子化模型认为，能力由许多离散的"知识块"组成，每块的使用频率服从幂律。模型按频率从高到低一块块学会，每一块都是突然学会的，但成千上万块加起来，损失曲线就是平滑的幂律。这个模型同时解释了"能力会突然涌现"和"损失平滑下降"。
叠加态的几何。 Liu、Liu 和 Gore 在 NeurIPS 2025 上指出：特征数远多于维度时（强叠加），损失主要来自特征向量之间的几何重叠，大约按维度的倒数下降，而且对特征频率的分布不敏感。他们报告开源 LLM 看起来正处在强叠加区，和 Chinchilla 的结果相符。今天 demo 里的八面体和反棱柱，就是这种"重叠"在 3 维里的样子。
这几类解释并不互斥，很可能在不同条件下由不同的机制主导。能区分它们的实验很少，这本身就是一个需要巡天的问题。和你的关系也很直接：量子化模型说的"一块块学会"，对应你的 RI 激活事件；叠加态说的几何重叠，对应今天的多面体。如果你的巡天能直接看见每一块在第几步被学会，就是在给 scaling law 的机制提供第谷式的数据。

几架望远镜之间是什么关系

它们的差别主要在空间尺度，也就是在模型内部看多细。时间上它们几乎都停在同一个点。

| 工具 | 看什么 | 类比 |
|---|---|---|
| 线性探针 | 你先指定一个概念，问它在某一层能不能读出来 | 带滤光片对准一颗已知的星 |
| SAE | 不用先给假设，把一层的激活拆成成千上万个稀疏特征 | 对一片天区做广角普查，列出所有点源 |
| 归因图 | 针对一个具体输入，追踪特征怎么跨层传递、最后产生输出 | 追踪一颗流星的完整轨迹 |

按空间尺度从小到大排：一个方向（探针）、一层的全部特征（SAE）、跨层的一条通路（归因图）、整个模型的总体表现（loss、scaling law）。

时间上，前三架几乎都只在一个 checkpoint、一次前向传播里看。训练时间这根轴上的仪器很少，只有 SAE-Track、devinterp 的 LLC、你的 RI 这几样。这根轴就是你的位置。

还有一个维度是"看"还是"动手"：上面这些都是观测；activation patching、steering 是直接改动模型内部看结果，属于实验。

用大白话说训练动力学巡天

用同一把尺子，从头到尾记录成千上万次训练，看在什么条件下会出现什么现象，再从这张大表里找规律。

拿你熟悉的心血管来类比：Framingham 心脏研究从 1948 年开始，给一个小镇上几千个居民按同一套标准做了几十年的定期体检，最后才确认高血压、高胆固醇、吸烟是危险因素。在那之前，医生对心脏病的了解主要来自一个个病例。

训练动力学巡天，就是给神经网络做 Framingham：不研究某一次训练，而是用统一的体检表，给在不同条件下"长大"的成千上万个网络做全程记录，看哪些发育规律是普遍的，在什么条件下会改变。最后的成果可能像一张赫罗图：每次训练是图上一个点，它们落在几条带子上，而那几条带子正是需要理论来解释的东西。
