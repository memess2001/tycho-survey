条件を系統的に変えながら数千の小さなネットワークを学習させ、各学習の全過程を一つの較正済み計測装置、refined information（RI）で測ります。どの測定も同じ問いに答えます：どの変数が、何次で、学習の何ステップ目に相互作用し始めるか。

天文学から借りた二つの図

分光器は一つの天体を精密に測り、掃天観測は多くの天体を同じ方法で測ります。

このプロジェクトは天文学の二つの考え方を借りているので、スペクトル、掃天観測（サーベイ）、カタログといった言葉が出てきます。それぞれがここで何を意味するかを説明します。

なぜ必要か

学習ダイナミクスには多くの現象があるが、共通の物差しがない

グロッキング、二重降下、段階的な文脈内学習、パリティ学習の「隠れた進歩」は、いずれも特定の設定で見つかりました。別の設定でも起きるのか、境界はどこかを測った例は少なく、較正済みの装置で測った例はありません。LLM 科学の三つの分野は異なる段階にあります：

計測装置

Refined information：先生の論文のとおりに実装

Enouen & Sugiyama（TMLR 2026）の定義1、階層的な集合族 I に対して：

RII,S(p) = DKL(pI+S ; pI)

付録 C.1 の、鎖の順序によらない二つの値を使います：

  • RImargS（I = P(S) − S）をサーベイでの部分集合ごとの「スペクトル線」とします。S 自身の小さな表だけで計算できるので、数十変数の 4〜5 次までの全部分集合を走査できます。
  • RIcondS（I = P([d]) − {T ⊇ S}）は、小さな変数集合についてのみ報告します。

{∅} から始まる完全な鎖は D(p; u) を正確に分解します。数値誤差は 2·10⁻¹¹ です。

N 個のプローブ標本からの推定：

G² = 2N · RÎ ~ χ²df, df = Π(ki − 1)

これにより部分集合ごとの p 値とバイアス補正 RÎ − df/2N が得られます。各チェックポイントで部分集合間に Benjamini–Hochberg を適用し、q ≤ 0.01 かつ RI ≥ min_effect のとき検出とします。min_effect は較正から決めます。

最初の試験観測

答えが分かっている二つのネットワーク：装置は正しい部分集合を正しい時点で見つけた

陽性対照とは、相互作用の構造を自分たちで設定したタスクです。以下の各対照は一回の学習で、学習中の 30 チェックポイントで RI を測っています。

スパースパリティ：ラベル = 20 入力ビットのうち隠れた 3 ビットの XOR

テスト精度 埋め込んだ部分集合 {x₁₀, x₁₂, x₁₅, ŷ} の RI 残り 1,349 部分集合の最大 RI log 2

学習終了時に検出されるのは一つだけ：埋め込んだ 4次の部分集合で、0.688 nats（理論値 log 2 = 0.693）。その内部のペアや三つ組は一度も活性化しないので、純粋なシナジーです。相互作用はステップ 975〜1,363 の間（網掛け）に現れ、テスト精度が 90% に達するステップ 1,538 より前です。MLP 幅 512、SGD、lr 0.05。ステップ 0 は 1 の位置に描画。

次数を埋め込んだトークン言語：2次と3次の依存

2次：{x[t−1], x̂} 3次：{x[t−1], x[t−3], x̂} 情報源から計算した真値

二値トークン。次のトークンは x[t−1]（結合 1.0）と x[t−1]·x[t−3]（結合 0.8）に依存します。ネットワークはまず 2次の項を（ステップ約 14 から）、後から 3次の項を（ステップ 69〜96 の間に発現し、10k でもまだ成長中）学習します：予測どおり低次から高次へ。最終的に 21 候補のうち検出されるのはこの二つだけで、0.1727 と 0.1142 nats（真値 0.1728 と 0.1209）。

先生に伺いたいこと

特にご意見をいただきたい点

  1. イベントにはどちらの値を使うべきか。イベント検出には RImarg（安価で、帰無分布は χ²）を使い、RIcond は小さな変数集合についてのみ報告しています。この分担は妥当でしょうか。それとも RIcond の発現を別種のイベントとして追跡すべきでしょうか。
  2. 疎な表での高次の推定。小さな部分集合の網羅的な走査を超えて、より大きな変数集合に MAHGenTa のサンプリング手法は役立つでしょうか。
  3. 離散化による人工物。閾値処理で生じる相互作用を、情報幾何的に補正する方法はあるでしょうか。たとえば潜在モデルの射影と比較するなど。
  4. トークン変数。多値のまま（自由度は Π(k−1) で増える）にすべきか、二値化すべきか。
  5. 時間方向の検定。チェックポイントごとの BH と持続性ルールで十分でしょうか。それとも発現の判定には逐次検定や変化点検定を使うべきでしょうか。
