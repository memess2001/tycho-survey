For scale: GPT-2 small has 124 million parameters. These tasks are small enough to run thousands of times, and their structure is known, so the instrument can be checked.

这一页介绍第一轮巡天观测的五种任务，都是小模型，参数量从 120 到 3.6 万，每次训练在一个 CPU 核上 10 到 90 秒。 稀疏奇偶：输入是 16 到 32 个随机比特，标签是其中 2 到 3 个隐藏比特的异或；单层 MLP；一共 4,623 次训练。它的答案已知，而且典型现象是长时间平台期后突然学会。 马尔可夫语言：二值 token 序列，下一个 token 依赖前面 token 的方式是我预先设定的（2 到 4 阶）；21 次。这是用 token 当变量的阳性对照。 模加法：(a + b) mod p，p 是 23 或 47，用 30% 到 70% 的组合训练；2,166 次。用来观察 grokking。 上下文马尔可夫链：每条 48 个 token 的序列都有自己的随机转移表；两层只含注意力的 transformer；21 次。用来观察先学 unigram、再学 bigram 的分阶段学习，也就是计划里的 B。 叠加态玩具模型：20 个稀疏特征压进 5 维；120 个参数；24 次。用来观察特征的几何结构。 作为对比，GPT-2 small 有 1.24 亿参数。这些任务足够小，可以跑几千次，而且结构已知，适合检查仪器。
