Tycho：用校准过的尺子，巡天观测网络如何学习

在系统变化的条件下训练成千上万个小网络，用同一把校准过的尺子——refined information（RI）——记录每一次训练的全过程。每次测量回答同一个问题：哪些变量、在第几步、以几阶的方式开始交互？

为什么要做

训练动力学有很多现象，却没有一把共同的尺子

grokking、双下降、分阶段的上下文学习、奇偶学习中的隐藏进展，都是各自在某一个特定设置下发现的。换个配置是否还在、边界在哪里，很少有人系统地测过，更没有用校准过的仪器测过。LLM 科学的三个分支处在不同阶段：

研究对象现状天文学对应
训练好的模型随规模的变化有经验律（scaling laws），没有公认机制开普勒之后，牛顿之前
一个模型内部有什么刚有新仪器（探针、SAE、归因图），规律还很少伽利略刚举起望远镜
训练过程如何随时间展开零散的观测，误差未知，彼此无法比较第谷之前

开普勒为了 8 角分的偏差放弃了圆轨道，前提是他知道第谷的仪器误差比这更小。所以计划是先校准仪器，再巡天：星表里的反常，只有相对于已知误差才有意义。

测量仪器

Refined information：按您的论文实现

Enouen & Sugiyama（TMLR 2026）的 Definition 1，对层次集合 I：

RII,S(p) = DKL(pI+S ; pI)

我们使用附录 C.1 中与链顺序无关的两个值：

  • RImargS（I = P(S) − S）作为巡天中每个子集的“谱线”。它只需要 S 自己的小表，所以几十个变量里 4–5 阶以内的子集都能全扫一遍。
  • RIcondS（I = P([d]) − {T ⊇ S}），只对小变量集报告。

从 {∅} 出发的完整链精确分解 D(p; u)，数值误差为 2·10⁻¹¹。

从 N 个探测样本估计：

G² = 2N · RÎ ~ χ²df, df = Π(ki − 1)

由此得到每个子集的 p 值和偏差校正 RÎ − df/2N。每个 checkpoint 上跨子集做 Benjamini–Hochberg。当 q ≤ 0.01 且 RI ≥ min_effect 时判定为检出，min_effect 来自校准。

第一次试观测

两个答案已知的网络：仪器在正确的时间认出了正确的子集

阳性对照是交互结构由我们自己设定的任务。下面每个对照都是一次训练，训练过程中在 30 个 checkpoint 上测量 RI。

稀疏奇偶：标签 = 20 个输入位中 3 个隐藏位的 XOR

测试准确率 预埋子集 {x₁₀, x₁₂, x₁₅, ŷ} 的 RI 其余 1,349 个子集中的最大 RI log 2

训练结束时只检出一个子集：预埋的 4 阶子集，0.688 nats，理论值 log 2 = 0.693。它内部的任何二元组、三元组都从未被激活，所以是纯协同。交互在第 975–1,363 步之间出现（阴影），早于测试准确率在第 1,538 步达到 90%。MLP 宽度 512，SGD，lr 0.05；第 0 步画在 1 处。

预设阶数的 token 语言：一个 2 阶依赖和一个 3 阶依赖

2 阶：{x[t−1], x̂} 3 阶：{x[t−1], x[t−3], x̂} 由数据源算出的真值

二值 token；下一个 token 依赖 x[t−1]（耦合 1.0）和 x[t−1]·x[t−3]（耦合 0.8）。网络先学会二阶项（约第 14 步起），后学会三阶项（在第 69–96 步之间出现，到 10k 步仍在增长）：先低阶后高阶，与预期一致。训练结束时，21 个候选子集中只检出这两个，分别为 0.1727 和 0.1142 nats，真值为 0.1728 和 0.1209。

  6. 事件 → 暂现源推送到手机

比天文学幸运的一点是：这片天空可以重新观测。每次训练都能在 CPU 上逐位重放，所以有意思的训练可以之后在转变点附近用更密的 RI checkpoint 再看一遍，也可以加扰动重跑，把观测变成实验。

想请教您的问题

最需要您判断的地方

  1. 事件用哪个值？我们用 RImarg 检测事件（便宜，零分布是 χ²），RIcond 只对小变量集报告。这样分工合适吗？还是应该把 RIcond 的激活作为另一类事件单独追踪？
  2. 稀疏表上的高阶估计。除了对小子集做穷举扫描，MAHGenTa 的采样方法对更大的变量集是否有帮助？
  3. 离散化伪影。有没有信息几何的方法来校正阈值化造成的交互，比如与某个潜变量模型的投影做比较？
  4. token 变量。应该保持多值（自由度按 Π(k−1) 增长），还是二值化？
  5. 时间上的检验。每个 checkpoint 做 BH 再加持续性规则够用吗？还是应该用序贯检验或变点检验来判定激活？
