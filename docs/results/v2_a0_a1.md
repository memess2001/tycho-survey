# Sky v2, steps A0 and A1: definitions, calibration under correlated probes, and known answers

14 November 2026. Design: [v2_design_draft.md](v2_design_draft.md) §4. A0 fixes the definitions and calibrates the
instrument for correlated probes. A1 checks the estimators on constructed cases whose answers are known exactly.
Both are instrument work, done before any v2 data exist and before the Part A pre-registration. Code:
`tycho/ri/cells.py`, `tycho/calibration/correlated.py`, `scripts/analysis_v2/a0_e8_calibration.py`,
`scripts/analysis_v2/a1_known_answers.py`. Tests: `tests/test_ri_cells.py`. Numbers:
[a0_e8_calibration.json](v2_analysis/a0_e8_calibration.json),
[a1_known_answers.json](v2_analysis/a1_known_answers.json).

## A0. Definitions

**Setting.** Inputs are binary, x ∈ {0, 1}^d, with spin s = 2x − 1. The output ŷ is binary and recorded as a soft
probability p1 = P(ŷ = 1 | probe row), as in v1. Write m = 2 p1 − 1 and χ_B = Π_{i∈B} s_i. Each checkpoint has two
probe sets, both drawn from deterministic seeds so that every table can be rebuilt exactly (A3):
* **data probes**, drawn from the task's own input distribution D, which may be correlated;
* **uniform probes**, used only for the function-level η coefficient.

**Measures.** For a subset A of the inputs:

| view | measure | definition | depends on D? |
|---|---|---|---|
| θ | `ri_marg` | local RI of the marginal table of A ∪ {ŷ} on data probes (v1's spectral line; RI^marg of Enouen & Sugiyama) | yes |
| θ | `ri_cond` | conditional (purified) RI of A ∪ {ŷ} given a conditioning set C ⊇ A of inputs, on data probes (RI^cond) | no, if C holds every input the output uses |
| θ | `w` | logit coefficient: Walsh coefficient of atanh(m) = logit/2 on A | no (property of the function) |
| η | `eta_u` | information value of f_u, the Walsh coefficient of m on A under uniform inputs (uniform-cell estimator on uniform probes) | no (property of the function) |
| η | `eta_d` | information value of m_D = E_D[m χ_A], the data moment | yes |

* **Information scale.** η coefficients are put in nats as the mutual information of a binary input with an output
  of mean f(∅) + f·s. That is h((1 + f(∅))/2) − ½[h((1 + f(∅) + f)/2) + h((1 + f(∅) − f)/2)], which equals the
  single-mode value at f(∅) = 0. It includes the output's base rate, so a biased output does not create θ-only
  artefacts (A3, item 4).
* **One gate for all four measures.** Each value v is corrected to max(0, v − 1/(2n)) and given the p-value
  χ²_1.sf(2 n v). BH is applied within a family at α = 0.01, and a detection also needs corrected ≥ min_effect.
  The comparison between views is therefore never a comparison between gates.

**Estimators.**
* **Cell statistics.** For each kept subset, store the count N_x and the output sum S_x = Σ(2 p1 − 1) of every cell
  x of A (`tycho.ri.cells.cell_stats`). These are sufficient for everything on the marginal table: `ri_marg`, the
  data moments, f(∅), the uniform-cell coefficients and the logit coefficients.
* **Conditional RI.** It needs the table of C ∪ {ŷ}. For a binary output it equals the drop in weighted
  cross-entropy when the feature χ_A is added to a logistic regression on the features χ_B, B ⊆ C, B ⊉ A. Every
  input-only term is free in that model, so the input margin is fitted exactly, and the regression uses cell
  weights N_x/n and soft targets (`conditional_ri_plugin`, damped Newton). It agrees with the iterative
  proportional fitting of `tycho.ri.refined.conditional_ri` to within 1 % (test) and is about 75 times faster.
* **Conditioning set.** In Part A, C is the whole table (at most 8 inputs). E8 shows how the noise floor grows with
  table size. The choice of C for transformers (Part B) is still open.

**Storage, for when the runner is extended in A2.**
* Per checkpoint and probe set: f(∅) and the seeds.
* Per kept subset: N_x and S_x for every cell (2^k numbers each).
* For conditional RI: N_x and S_x of the full table of C (2^|C| each).

The Fourier rows of v1 are replaced by these statistics.

## A0. Calibration experiment E8: nulls under correlated probes

**Design** (`tycho.calibration.correlated`, module docstring).
* The table inputs form two independent blocks. Each block is uniform, a Markov chain (ρ = 0.5, 0.9) or
  equicorrelated (ρ = 0.3, 0.6) inside.
* The teacher uses the first block (additive log-odds plus random pair terms) and four nuisance inputs the
  instrument never sees. It ignores the second block.
* So every subset that contains a second-block input has conditional RI exactly 0, and subsets of the second block
  alone also have marginal RI exactly 0. The exact population values of the tested nulls are at most 2.7e-16.
* Grid: tables of 4, 6 and 8 inputs; n = 1,024, 4,096 and 16,384; nuisance scale 0.5 and 2.0; 300 replicates per
  cell; 90 cells.
* The nuisance inputs are what makes the estimates noisy. With a soft output and every input in the table, a cell
  mean is exact and the plug-in value of a null is 0 to machine precision (found in a first version of E8).

**Results** ([a0_e8_calibration.json](v2_analysis/a0_e8_calibration.json)):

| null | values | false-positive rate at α = 0.01 (pooled) | worst cell | plug-in mean / χ² mean |
|---|---|---|---|---|
| conditional, pair | 54,000 | 0.24 % | 1.2 % | 0.27 to 0.89 |
| conditional, triple | 54,000 | 0.23 % | 1.8 % | 0.18 to 1.14 |
| marginal, pair | 27,000 | 0.34 % | 1.7 % | 0.48 to 1.04 |
| marginal, triple | 27,000 | 0.26 % | 1.3 % | 0.52 to 0.96 |

* **The χ²_1 test is valid and conservative** for both RI variants under every probe kind and correlation. With a
  soft output only the nuisance inputs add noise, so the null values are smaller than χ² predicts (as v1 noted for
  soft columns), and the p-values pile up near 1 (KS distance 0.14 to 0.42).
* **The one cell above nominal** is the sparsest: n = 1,024 with 8 inputs (4 rows per cell), uniform probes and
  strong nuisance. There the conditional-triple rate is 1.8 % and the plug-in mean is 1.14 times χ².

**Recommended min_effect for conditional RI.** v1's rule, max(0.001, 0.99 quantile of the corrected null values
over all probe kinds, correlations and nuisance strengths):

| n | 4 inputs | 6 inputs | 8 inputs | v1 marginal min_effect |
|---|---|---|---|---|
| 1,024 | 0.0023 | 0.0025 | 0.0035 | 0.0029 |
| 4,096 | 0.001 | 0.001 | 0.001 | 0.001 |
| 16,384 | 0.001 | 0.001 | 0.001 | 0.001 |

At n ≥ 4,096 the noise floor (0.99 quantile ≤ 0.0007 nats at 4,096, ≤ 0.00016 at 16,384) is below the policy floor,
so conditional RI uses the same min_effect as marginal RI. At n = 1,024 its threshold is 0.0023 to 0.0035 nats,
growing with table size, against 0.0029 for marginal RI.

## A1. Known answers

Four families ([a1_known_answers.json](v2_analysis/a1_known_answers.json)). The estimates use n = 4,096 data
probes plus 4,096 uniform probes, 100 replicates, BH within each family at α = 0.01, and min_effect 0.001 for all
four measures (E8 at n = 4,096). "Present" means an exact value ≥ min_effect.

**Family 1: the attribution map.** Three inputs, uniform probes, log-odds / 2 = s (χ0 + λ χ1 + λ χ2) + b χ012.
Saturation s and lower-order strength λ are crossed knobs, and b is chosen in three ways:
* *θ-null*: b = 0, so there is no top log-odds term;
* *η-null*: b = b*, so the top Walsh coefficient is exactly 0;
* *both*: b = 0.3.

The constructions are exact: |w_top| ≤ 1.2e-10 for θ-null and |f_u| ≤ 1.4e-13 for η-null. Exact classes without
nuisance inputs (θ-null / η-null / both), with the teacher's largest |m|:

| s \ λ | 0.3 | 0.6 | 1.0 |
|---|---|---|---|
| 0.25 | neither / neither / both (0.38) | neither / neither / both (0.50) | neither / neither / both (0.64) |
| 0.5 | neither / neither / both (0.66) | **η-only / θ-only** / both (0.80) | **η-only / θ-only** / both (0.91) |
| 1 | **η-only / θ-only** / both (0.92) | **η-only / θ-only** / θ-only (0.98) | **η-only / θ-only** / both (1.00) |
| 2 | **η-only / θ-only** / θ-only (1.00) | **η-only / θ-only** / η-only (1.00) | **η-only / θ-only** / η-only (1.00) |
| 3 | neither / neither / neither (1.00) | **η-only / θ-only** / η-only (1.00) | **η-only / θ-only** / η-only (1.00) |

* **The views diverge only with saturation and lower-order terms together.** Below a largest |m| of about 0.8 they
  never diverge. Above it they diverge in both directions by construction: η-only up to 0.129 nats with RI exactly
  0, and θ-only up to 0.019 nats with the Walsh coefficient exactly 0. This is the A3 law, now with exact answers.
* **Saturation also hides a present log-odds term.** With b = 0.3 the top log-odds term is present in every row.
  Under strong saturation, however, it carries almost no information (η-only or θ-only in 6 of 15 cells), because
  a log-odds term matters little where the output is nearly deterministic. With λ = 0.3 at s = 3 one input
  saturates the output alone and nothing is left to diverge.
* **The estimates reproduce the exact classes.** With four nuisance inputs (exact values recomputed on the
  marginalised table), the estimated class matches the exact one in 95.0 % of replicates over all 45 teachers. Over
  the 35 clear cases, where both exact values are ≥ 2 × or ≤ 0.5 × min_effect, it matches in 99.9 % (min 95 %).
  The misses are near the threshold.

**Family 2: probability-scale products.** A soft AND has every order present in both views. Its RI falls with order
(0.051, 0.016, 0.013 nats at ε = 0.05), while its Walsh coefficients are equal at every order. A soft XOR has only
the top set, in both views (0.046 and 0.495 nats at c = 0.3 and 0.9). Neither diverges: products on the probability
scale are seen at the same orders by both views.

**Family 3: the v1 case.** These are the exact cell means of the DR1 divergence (A3's object 898791…, step 2206),
from the exact reconstruction. The exact values reproduce DR1:
* {0, 1, 2} is η-only, with RI 0.00017 nats (the stored plug-in is 0.00017) against η information 0.0103;
* the top log-odds coefficient is 0.066;
* the singletons are present in both views, and the pairs in neither.

**Family 4: correlated inputs.** Six table inputs plus four nuisance inputs. The probes are uniform, a Markov chain
(ρ = 0.5, 0.8, 0.95) or equicorrelated (ρ = 0.3, 0.6). Four teachers use inputs 0 and 2 only: a copy of x0, additive
x0 + x2, x0 with an x0x2 term, and a pure x0x2 term. All 21 subsets of one or two inputs are tested. A *spurious* set
contains an input the teacher does not use (18 of the 21).

| measure | spurious sets present, exact (24 cases) | spurious detections, estimated | recall where exact present | detections where exact absent |
|---|---|---|---|---|
| `ri_marg` | 144 (up to 18 of 18 per case) | 139.3 | 0.98 (min 0.86) | 0.7 % (max 6.6 %) |
| `ri_cond` | **0** | **0** | 1.00 (min 0.99) | 0.0 % |
| `eta_u` | **0** | 0.02 | 1.00 | 0.0 % |
| `eta_d` | 187 (up to 18 of 18) | 183.1 | 0.99 (min 0.83) | 0.3 % (max 3.4 %) |

**Spurious structure.** Marginal RI and the data moment report every input that is correlated with a used one, as
designed. Conditional RI and the uniform Walsh coefficient report none. The estimates follow the exact values in
every case.

**The price of conditioning.** For the pure-pair teacher the planted pair {0, 2} shrinks as follows:

| probes | `ri_cond` (detection rate) | `ri_marg` | `eta_u` | `eta_d` |
|---|---|---|---|---|
| uniform | 0.124 (1.00) | 0.124 | 0.124 | 0.124 |
| Markov ρ = 0.5 | 0.056 (1.00) | 0.116 | 0.124 | 0.126 |
| Markov ρ = 0.8 | 0.0100 (1.00) | 0.074 | 0.124 | 0.142 |
| Markov ρ = 0.95 | 0.00064 (0.02) | 0.024 | 0.124 | 0.169 |

Conditioning on strongly correlated neighbours leaves little information that is unique to the pair, so conditional
RI loses power: about 200 times smaller at ρ = 0.95, and no longer detected. With the x0 term added the same
happens (0.078 → 0.0004).

**Why the uniform Walsh coefficient wins here, and why that may not carry over.** It keeps full power and reports
nothing spurious at every correlation. That is because a constructed teacher is defined, and correct, on every
input, including inputs the data distribution never produces. A trained network is only constrained where it was
trained. Off the data distribution its output is whatever training left there. A1 therefore favours the uniform
coefficient by construction.

## What A0 and A1 mean for Part A

1. **The instrument is ready for correlated probes.** Conditional RI has a fast, verified estimator and a valid,
   conservative test. Its min_effect equals marginal RI's at n ≥ 4,096. Tables of up to 8 inputs are fine at
   n ≥ 4,096.
2. **The four measures answer different questions, as constructed.**
   * Marginal RI and the data moment describe the data-plus-model joint, including correlations the model never
     used.
   * Conditional RI describes the model's own log-odds, using only inputs the data produces, but loses power when
     inputs are redundant.
   * The uniform Walsh coefficient describes the model's function everywhere, including where the data never goes.
3. **A sharp question for A2 (trained networks).** On correlated training data, does the uniform coefficient keep
   its A1 advantage, or does the network's untrained off-distribution behaviour make it report spurious or missing
   structure? Conditional RI does not depend on that behaviour. This is where θ can beat η by a referee, and it can
   be pre-registered.
4. **The attribution divergence needs saturation ≥ about 0.8 with lower-order terms** (A1 family 1, A3). Any
   referee comparison of θ against η on attribution has to be run in that regime.

## Limits

* **Constructed teachers, not trained networks** (see above).
* **Soft outputs.** A hard (sampled) output would make the null closer to χ² and less conservative. It is not
  calibrated here.
* **The E8 nulls are of two kinds:** inputs the model ignores, and subsets of them. A null among inputs the model
  uses, with some of its other inputs left out of the table, is not exactly 0 for conditional RI (marginalisation).
  That case belongs to the open choice of the conditioning set.
* **Small tables.** Tables have at most 8 inputs and families at most 21 subsets. The noise floor grows with
  2^|C| / n.
